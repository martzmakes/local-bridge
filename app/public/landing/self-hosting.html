Self-hosting

Run it on your AWS account.

The Mac app uses your bridge endpoints. You control the AWS account, sign-in allowlist, and machine registrations.

  1. Prepare your AWS account. Create two hostnames in a Route 53 zone, an ACM certificate covering both names, and a verified SES sender. The stack deploys to US East (N. Virginia).
  2. Deploy the CDK stack. Set the HTTPS and WebSocket addresses, sender, and allowed emails. Create signing secrets in Systems Manager Parameter Store.
  3. Connect your Mac. Set the app’s HTTPS and WebSocket addresses to the ones from your stack, then sign in and add your MCP servers.

Deploying requires the source checkout. The repository is private while the open-source release is in preparation.
